Raspberry Pi 5

My Raspberry Pi 5 setup: the hardware, desk, OS and the dev and AI tools I use on it. Last updated 27 November 2026.

Hardware

  • Raspberry Pi 5 (8 GB)The computer I build most of the somaari apps on.
  • Samsung 256 GB NVMe SSDSamsung PM9B1. The Pi boots from it rather than a microSD card.
  • Waveshare 2-Ch PCIe FFC Adapter BoardSplits the Pi 5's PCIe connector into two; the NVMe drive connects through it.
  • Raspberry Pi Case for Raspberry Pi 5The official case.
  • Raspberry Pi Active CoolerThe official heatsink and fan.
  • Raspberry Pi 27W USB-C Power SupplyThe official 5.1 V, 5 A supply.

Desk

  • MSI 27-inch monitor
  • EvoFox Katana X2 TKL keyboardMechanical and tenkeyless, with clicky blue switches.
  • Ant Esports GM320 mouseWired, with RGB lighting.

OS and desktop

  • Raspberry Pi OS (64-bit)
  • XFCEThe desktop, in place of the default one.
  • Wallpaper slideshowMy own script that changes the desktop wallpaper.

Dev and AI

  • Claude CodeMost of the somaari apps are built with it, on the Pi.
  • VS Code
  • Neovim
  • tmux
  • GitHub CLI
  • Node.js
  • Python
  • uvPython packages and projects.
  • Docker
  • ObscuraThe headless browser Claude Code uses for web work.

My apps

  • somaari-diskMy disk-usage analyzer, on the Pi's desktop.
