Task Planner

somaari-plan

Available

A small planner that runs on your own Raspberry Pi. Turn Markdown plans, pasted notes or a quick line into dated tasks, with Today, calendar and board views.

Installation guide (somaari-plan) View on GitHub (somaari-plan)

Key capabilities

  • Plans in

    Upload a Markdown plan or paste text: headings become steps, list items become tasks, and dates in the text are read by rules, not guessed.

  • Review before saving

    An editable preview of every task, with flagged tasks to check and skipped lines you can restore with one click.

  • Today, Calendar and Dashboard

    Today's list by priority; day, week and month views; and a 7-day board to drag tasks across.

Platforms

  • A Raspberry Pi 5, any Raspberry Pi with a 64-bit OS, or any Linux machine
  • Used from a web browser on your network, on a computer or a phone

What you need

  • Python 3.11 or newer, git and uv
  • Optional: a TypeSafe API key for the default AI mode. An LLM key works instead, or turn AI off
