Disk Usage Analyzer

somaari-disk

Available No AI

See what is using space on your drives, largest items first. Read-only and fully offline, for Linux (Raspberry Pi OS, Debian, Ubuntu and more) and Windows 10/11.

Download (somaari-disk) Documentation (somaari-disk) View on GitHub (somaari-disk)

The latest release has a .deb for Debian, Ubuntu and Raspberry Pi OS, and a Windows installer or portable zip.

Video

Watch on YouTube

Key capabilities

  • Largest items first

    Every folder's contents sorted by size, with a bar and share, so the big items are always at the top.

  • Every drive

    Internal disks, USB sticks, SD cards, NVMe and network shares; exFAT, NTFS, FAT32, ext4 and read-only mounts.

  • Move to Trash, never delete

    Scanning changes nothing. The only change it can make is Move to Trash, after you confirm, and the Trash can restore it.

Platforms

  • Debian 12+, Ubuntu 23.04+ and Raspberry Pi OS Bookworm (arm64 or x86-64)
  • Windows 10 (1803 or later) or Windows 11, 64-bit
  • Other Linux distributions, from source

What you need

  • On Linux: Python 3.11 or newer, GTK and WebKitGTK (the .deb installs them)
  • On Windows: the Microsoft Edge WebView2 Runtime (Windows 11 already has it)
