GPS Route Viewer

somaari-trip

Available No AI

See where you went each day on a map, from the Overland iOS app's GPS logs: trips, stops, distance and speed. It runs in Docker on your own Raspberry Pi 5 or x86_64 Linux server, so your location history stays there.

Documentation (somaari-trip) View on GitHub (somaari-trip)

Video

Watch on YouTube

Key capabilities

  • Trips and stops

    Routes are split into trips, and stops are detected where you stayed put, with the WiFi network and battery level.

  • Colour by mode or speed

    Walking, cycling, driving and more, or a green-to-red speed gradient.

  • Days and ranges

    One day, a custom range, or the past 3, 7 or all days, with totals for distance, time, speed, trips and stops.

Platforms

  • Server: a Raspberry Pi 5 (ARM64) or any x86_64 Linux server
  • Viewing: a web browser, on a computer or a phone
  • Recording: Overland on an iPhone

What you need

  • A Linux machine that stays on
  • Docker with the Compose plugin
  • Node.js 20 or newer, only to create the login hash (you can do that on another machine)
  • Overland for iOS
  • A network the phone can reach the server on: your home wifi, or ZeroTier or Tailscale for when you're away
